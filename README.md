中文
这是一个小游戏，里面有几首音乐，也可以自己上传，玩法太约是：有一个弹球，可以划动，电脑用户直接移动鼠标，游戏会随机生成墙，要做的就是从空里穿过去。


English
This is a small game with several pieces of music included, and you can also upload your own. The gameplay is roughly like this: there is a bouncing ball that can be swiped. For computer users, you simply move the mouse, and the game will randomly generate walls. What you need to do is to pass through the gaps.
